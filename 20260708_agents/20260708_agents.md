# OpenRouter Tool-Calling Agent (Python / TypeScript)

OpenRouter API を使って tool calling（function calling）が可能な AI エージェントを実装するサンプル。

## 概要

OpenAI SDK 経由で OpenRouter に接続し、ツール呼び出し可能な対話型エージェントを構築する。
`say_hello` と `get_weather` の2つのツールを定義し、モデルが適切にツールを選択・実行するデモ。

モデルは `deepseek/deepseek-v4-flash` を使用。

## 実装のポイント

- OpenRouter API の base URL は `https://openrouter.ai/api/v1`
- OpenAI SDK の `client.chat.completions.create` に `tools` パラメータを渡す
- モデルが `tool_calls` を返したら、対応する関数を実行し、結果を `tool` ロールで返す
- ツール定義（JSON Schema）と実際の関数実装を分離し、レジストリで紐付ける
